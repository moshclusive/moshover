# MosHover - Hover Previews for Windows Explorer

<p align="center"><img src="logo.png" alt="moshover logo" width="128"></p>

> A Windows tool (v2.0) that shows a floating preview whenever you hover the mouse over a file in Windows Explorer - images, PDFs, Photoshop files, videos, and archives - without opening anything.

## Features

- **Hover preview** - Hover over a file in Explorer and a floating preview window appears. Move the mouse away and it disappears.
- **Many formats** - Images, PDF (with AI/PS fallback), Photoshop PSD, video (with a click-seek slider), and archives (RAR via the bundled UnRAR helper, PDF/PS via Ghostscript).
- **Preview window** - Pan and zoom, resize by dragging the grip, file info with formatted sizes, and per-file-type preview-size presets.
- **Extras** - Clipboard history, a settings dialog, a system-tray controller, optional start-with-Windows registration, and single-instance protection.
- **Fully offline** - No network, no account, no sync. Settings and logs live under `%LOCALAPPDATA%\MosHover\`.

## Download & Install

1. Go to the [Releases](../../releases) page.
2. Download `MosHover-Setup.exe` and run it.
3. MosHover starts with Windows by default (you can turn that off in Settings).

## How to Use

1. Start MosHover (it sits in the system tray).
2. Hover over any file in Windows Explorer - a preview pops up next to the cursor.
3. Drag the preview's corner to resize it; use the mouse wheel or the slider to zoom and seek in videos.
4. Right-click the tray icon for Settings, Clipboard History, and Quit.

> **Optional helpers:** `Extras/UnRAR.exe` and `Extras/gswin64c.exe` (Ghostscript) enable archive and PostScript previews.
